Each box is a status. Below each status is who moves it there.

Every arrow writes one row to the audit log: who, when, old status, new status. Any move that is not in this diagram gets blocked by the backend.

Screens per persona

Customer

Phone first · no login
  1. Find order
  2. Pick items (eligibility shown)
  3. Reason + photo
  4. Refund method
  5. Return label with QR
  6. Status timeline

Warehouse agent

Desktop · keyboard + scanner
  1. Scan / type QR
  2. Grade each item A / B / C
  3. Accept, partially accept or reject

Finance reviewer

Desktop
  1. Queue of refunds above ₹10,000
  2. Review and approve or reject
  3. Mock gateway pays, ledger row written

Operations manager

Desktop · read only
  1. Return rate by category
  2. Top reasons
  3. Average cycle time
  4. Flagged customers
